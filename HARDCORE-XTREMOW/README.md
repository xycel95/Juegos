# HARDCORE XTREMOW · Pack de mods

Los tres mods que utiliza nuestro servidor de **Minecraft Java 1.21.1 con Fabric**, reunidos para poder compartirlos. Se conservan los archivos originales y sus licencias.

**[Descargar el ZIP completo](https://raw.githubusercontent.com/xycel95/Juegos/Minecraft/HARDCORE-XTREMOW/HARDCORE-XTREMOW-mods.zip)**

## Qué incluye

| Mod | Versión incluida | Para qué sirve | Enlaces |
| --- | --- | --- | --- |
| **Fabric API** | `0.116.15+1.21.1` | Biblioteca de apoyo para mods de Fabric. | [JAR](https://raw.githubusercontent.com/xycel95/Juegos/Minecraft/HARDCORE-XTREMOW/mods/fabric-api-0.116.15%2B1.21.1.jar) · [Proyecto](https://github.com/FabricMC/fabric) |

También puedes abrir la [carpeta de mods](mods/) o descargar cada archivo por separado.

## Antes de utilizarlos

Este ZIP reúne los archivos instalados en el servidor; no incluye Minecraft, Java, Fabric Loader, mundos ni la dirección de conexión. Los mods del servidor no son necesariamente requisitos del cliente. Consulta los proyectos enlazados para decidir dónde instalar cada componente.

**HardcoreWorldReset reinicia el mundo cuando muere un jugador.** Es parte de la dinámica de esta serie; tenlo en cuenta si utilizas el mod en otra partida.

Para solicitar acceso a nuestro servidor, utiliza el [formulario de la web](https://xycel95.es/minecraft/#ticket-form). Los datos de conexión se facilitan por privado.
